# M0 performance

Measured 2026-11-07 with `scripts/measure.py` on the release build (thin LTO,
stripped), unless noted.

## Machine

| | |
|---|---|
| CPU | AMD Strix (20 threads) |
| GPU | AMD Radeon 880M/890M (integrated), Vulkan via Mesa |
| Session | GNOME Shell 50.1, Wayland, fractional scaling enabled (`scale-monitor-framebuffer`) |
| Kernel | 7.0.0-113038-tuxedo |
| Window | 1600×1000 logical, 3 panes, 4 views, client-side decorations |

Every run checked that a real window was used: `libvulkan` mapped and `ZED_HEADLESS`
unset.

|---|---|---|---|

warm-up; after that memory is flat.

## Cross-window tab drag (review finding 1)

- Wayland: not possible with GPUI's typed drag. Windows have no global coordinates
  and the OS drag only carries files (checked in the GPUI sources by the reviewer).
- X11: not verified automatically. Driving a real pointer across a live desktop was
  judged too intrusive; GNOME's focus-stealing prevention also refused xdotool's window
  activation, so synthetic input was unreliable.
- Detach and re-attach work by button, key (ctrl shift d / ctrl shift a) and by
  closing the detached window. Proposed amendment to R3.8: re-attach "by dragging it
  back where the platform allows, and always from its menu, key or window close".

## Notes

- The 4 idle wakeups per second come from two `blocking-*` threads (2/s each). To
  identify in M1; harmless at 0.05 % CPU.
- With the cluster feed on, the deployments view re-renders once per 15 s poll even
  when nothing changed. M3 will only notify on change (and use watches, not polls).
- RSS includes shared libraries and GPU driver mappings; PSS and USS are the numbers
  that grow with devdeck's own use.
- Binary size is dominated by wgpu, the kube client with rustls, tokio and the font
  (430 KB). Not a goal yet; fat LTO and `opt-level = "s"` for the GPU-free parts can be
  tried in M4.
- The 50 000-line demo uses `Vec<String>` in a virtualized list; the real command
  output view (alacritty_terminal grid, M2) will be measured on its own.
